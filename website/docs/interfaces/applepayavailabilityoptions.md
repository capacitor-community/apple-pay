A config object for [ApplePay.canMakePayments](../classes/applepay#canmakepayments)

## Properties

### merchantIdentifier

- Type: `string`

The merchant identifier you registered with Apple for use with Apple Pay.

### supportedNetworks

- Type: [ApplePaySupportedNetwork](../enums/applepaysupportednetwork)

An array of supported networks that will be supported.
